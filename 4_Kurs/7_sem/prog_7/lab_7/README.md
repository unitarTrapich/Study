# Лабораторная работа №7
### Разработка REST API и работа с OpenAPI

## 1. Инструкция

Данный проект представляет собой систему управления библиотекой (Library Management System), реализованную на фреймворке FastAPI.

### Предварительные требования
* Python 3.8 или выше
* Установленный менеджер пакетов pip

### Установкa и запуск
1. **Установить необходимые библиотеки:**
   ```bash
   pip install fastapi uvicorn pydantic
2. **Запуститт сервер:**

    ```bash
    uvicorn main:app --reload
    ```
    Параметр --reload позволяет серверу автоматически перезагружаться при изменении кода.

3. **Доступ к интерфейсам:**

* API эндпоинты: http://127.0.0.1:8000

* Интерактивная документация Swagger UI: http://127.0.0.1:8000/docs

* Альтернативная документация ReDoc: http://127.0.0.1:8000/redoc*
