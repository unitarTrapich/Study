# Лабораторная работа №5  
Формы и аутентификация пользователей в Django

## Цель работы
Изучить работу с формами в Django и встроенной системой аутентификации.  
В рамках работы реализованы регистрация и вход пользователей, а также создание опросов через HTML-формы.

---

## Задачи
- Реализовать приложение `pll` для работы с опросами
- Добавить возможность голосования и просмотра результатов
- Реализовать регистрацию, вход и выход пользователей
- Ограничить доступ к отдельным страницам для неавторизованных пользователей

---

## Структура проекта
- **Проект:** `mainf`
- **Приложение:** `pll`

### Модели
- `Question` — вопрос опроса
- `Choice` — вариант ответа с количеством голосов

### Формы
- `PollCreateForm` — создание нового опроса
- `RegisterForm` — регистрация пользователя

### Представления
- список опросов, голосование и результаты
- создание опроса (только для авторизованных)
- регистрация, вход и выход пользователя

### Шаблоны
- `base.html` — общий шаблон с навигацией

---

## Тестовый пользователь
- Логин: `student`
- Пароль: `student12345`
- Имеет доступ к админ-панели `/admin/`

---

## Основные URL
- `/polls/` — список опросов  
- `/polls/create/` — создание опроса  
- `/register/` — регистрация  
- `/login/` — вход  
- `/logout/` — выход  
- `/admin/` — админ-панель  

---

## Вывод
В ходе работы было создано Django-приложение с поддержкой аутентификации пользователей и работы с формами. Реализованы регистрация, вход и выход, создание опросов и защита страниц с помощью `login_required`. Интерфейс оформлен с использованием Bootstrap и общего шаблона.
