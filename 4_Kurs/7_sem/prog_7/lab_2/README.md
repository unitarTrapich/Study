# Лабораторная работа №2 
### Микросервисный агрегатор погоды

Реализован набор микросервисов для получения данных о погоде, формирования рекомендаций и ведения истории запросов.

## Выполнено
- **Получение погоды**: запрос данных у OpenWeatherMap через `multiprocessing`.
- **Рекомендации**: анализ погоды и советы пользователю.
- **История**: храненик данных о предыдущих запросах.

## Исполнение

### Локально:
1. Установить библиотеки: `pip install -r requirements.txt`.
2. Запустить: `python app.py`.
3. Сервис доступен по адресу: `http://localhost:8080`.

### Через Docker:
1. Соберать образ: `docker build -t weather-app .`.
2. Запустить контейнер: `docker run -p 8080:8080 weather-app`.

### Развертывание в Yandex Cloud:
1. Загрузить образ в Yandex Container Registry.
2. Создайть Serverless Container на основе загруженного образа.
3. Установить порт 8080 в настройках контейнера.

## Примеры использования
- `GET /weather?city=London` — получить данные о погоде.
- `GET /history` — посмотреть историю последних поисков.
- `POST /recommend` — отправить JSON с погодой для получения совета.
